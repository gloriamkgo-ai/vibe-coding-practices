# 노을 정원의 고양이

해 질 녘 사원 정원에서 장화 신은 고양이를 3인칭으로 조종해 영혼의 구슬 7개를 모으는 블록 3D 브라우저 게임입니다. 설계는 저장소 루트의 `PLAN.md`를 따릅니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 타입 검사 + 배포용 빌드(dist/)
npm test         # 단위 테스트 + 자동 완주 테스트
```

## 조작

| 입력 | 동작 |
|---|---|
| W A S D / 방향키 | 이동 |
| 마우스 | 시점(화면을 클릭하면 마우스가 잠김) |
| Shift | 질주 |
| Space | 점프 |
| Esc / P | 일시정지 |

## 주소 옵션

- `?autopilot` — 자동 플레이. 사람이 누르는 것과 같은 입력으로 고양이를 움직여 구슬 7개를 모으는 데모입니다.
- `?speed=N` — 게임 시간 배속(1~8). 자동 플레이 시험용입니다.
- `?quality=low|medium|high` — 그래픽 품질을 강제로 정합니다.

## 구조

- `src/world` 블록 정의, 복셀 세계, 정원 배치(`layout.ts`), 구슬 위치, 메시 생성(보이는 면만 + 모서리 음영)
- `src/player` 물리(고정 시간 간격, 축별 충돌, 턱 오르기, 코요테 타임, 점프 버퍼), 고양이 모델, 카메라 레이캐스트
- `src/render` 노을 하늘, 조명·그림자·안개, 지형, 원경, 반딧불, 벚꽃잎, 구슬, 불꽃놀이, 후처리(빛 번짐)
- `src/systems` 자동 조종, 나침반, 효과음(Web Audio 합성), 실행 상태
- `src/ui` 타이틀, HUD, 일시정지·설정, 결과
- `src/tests` 충돌·레이캐스트·나침반 단위 테스트와 자동 완주 테스트

외부 이미지·소리 파일은 없습니다. 질감, 모델, 효과음은 모두 코드로 만듭니다.
